麦尼海塘后台

在真实页面上直接修改文字、图片和板块，改完一键发布到网站。

怎样获得令牌
  1. 登录 GitHub，打开 Settings → Developer settings → Personal access tokens → Fine-grained tokens，点 Generate new token。
  2. Repository access 选 Only select repositories，勾选 mainihaitang。
  3. Permissions → Repository permissions 里，把 Contents 设为 Read and write，其余保持默认。
  4. 生成后复制以 github_pat_ 开头的那串字符，粘贴到上面。

令牌只保存在你这台设备的浏览器里，不会发给除 GitHub 以外的任何地方。
