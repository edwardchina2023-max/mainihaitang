# 麦尼海塘 MANI GARDEN · 官网

线上地址：<https://www.mainihaitang.com>（GitHub Pages，自有域名，根路径发布）

这是黄海在理塘麦尼海塘的第一人称牧场档案站：我在远方、拉波日记、麦尼牧场、理塘风物、山中四季、求真溯源、风的消息。

## 网站后台

地址：<https://www.mainihaitang.com/admin/>（不会被搜索引擎收录）

- 第一次进入需要一个 GitHub 访问令牌（Fine-grained token，只授权 mainihaitang 仓库，Contents 设为 Read and write）。登录页里有获取步骤。
- 在真实页面上点选修改：文字直接打字；图片、视频点中后在右侧更换（图片会自动压缩成 WebP）；链接可改指向。
- 板块（以及板块里的卡片、段落）可以上移、下移、复制、删除，也可以从全站现有板块里挑一个样式插入。
- 新建页面：选一个现有页面作版式参照，可直接加入导航；页面设置里改标题、描述、分享图，也可以删除页面。
- 导航：一次修改，电脑版导航、手机目录、页脚同时更新；页眉页脚里的改动会同步到全站。
- 发布：右上角“发布”，改动作为一个版本提交，1–3 分钟后上线；未发布的修改会自动存在本机草稿里。
- 历史版本：可回到任意一次发布或备份（后台本身不受影响）。

发布后，`.github/workflows/site-check.yml`（“发布后自动整理”）会自动压缩新视频、生成封面、补齐 SEO 与站点地图并校验全站。

## 备份与恢复

| 备份 | 内容 | 创建时间 |
| --- | --- | --- |
| 分支 `backup/2026-10-18-before-optimization` | 2026-10-18 优化前的完整网站（提交 60baae4） | 2026-10-18 |
| 分支 `backup/2026-10-19-before-copy-rewrite` | 文案诗意化修订前的网站（提交 074a494） | 2026-10-19 |

恢复方式（任选其一，都会新建一个“恢复提交”，不改写历史，恢复后仍可再撤销）：

0. **后台**：历史版本 → 选一个备份或发布 → 恢复。
1. **GitHub 网页一键恢复**：仓库 → Actions → “一键恢复到备份版本” → Run workflow → 确认框输入 `RESTORE`。
2. **命令行**：`bash scripts/restore-backup.sh`（可在后面加其它备份分支名）。
3. **直接告诉 Claude “恢复麦尼海塘备份”**，由 Claude 执行第 2 种方式。

三种方式都只恢复网站文件，`admin/`、`.github/`、`scripts/` 保持现状，所以恢复后还能用后台再回到新版。恢复成优化前的旧网站后，自动整理流程会识别出来并跳过。

## 更新流程

日常改文字、换图片、调板块、加页面：用网站后台，发布后自动整理流程会处理其余事情。

如果从《行路不难》项目工作区重新导出整站：

```bash
node scripts/export-static.mjs /absolute/path/to/website/dist   # 1. 导出（会覆盖页面与 media）
python3 scripts/optimize-media.py                              # 2. 视频压缩、封面、品牌小图（已处理的自动跳过）
node scripts/optimize-static.mjs                               # 3. SEO、分享、视频懒加载、sitemap
node scripts/validate-static.mjs                               # 4. 发布前校验
```

新增视频后同样运行第 2–4 步，脚本会自动生成封面并改为按需播放。

## 媒体规范

- 图片：WebP，长边 ≤1600px。
- 视频：H.264 + faststart；首屏视频 1080p，其余长边 ≤1280px、帧率 ≤30。
- 只有首页首屏视频原生自动播放；其余视频进入视口才加载、静音循环；访客开启“减少动态效果”或省流量模式时不自动播放。

## 内容边界

公开站点只保存已分级的公开资料，不存证件、完整录音、联系方式、精确位置、未授权影像或完整账本。AI 未生成任何冒充现场的纪实影像。
